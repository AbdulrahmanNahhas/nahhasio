# Nahhasio 0.1.0

[Release notes index](README.md) · [Current deployment procedure](../operations/deployment.md)

The original Alpha hosting release introduced the rootless Fedora server, signed Flatpak client,
and coordinated catalog/artwork transfer. The signed release was published; the **2026-10-26**
[installation record](../operations/deployment.md#installed-family-pc-checkpoint--2026-10-26)
confirmed HTTPS readiness and client login/library access after the restore. That record does not
establish later backup/restore, reboot, update, or playback acceptance.

The original host worker needs the [one-time 0.1.1 bootstrap upgrade](0.1.1.md) before using the
later coordinated update protocol. For a new install or current upgrade, use the deployment guide
and [operations runbook](../operations/runbook.md), not the original transfer instructions.
