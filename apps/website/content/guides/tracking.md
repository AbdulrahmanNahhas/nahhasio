# Watch history and profiles

Each viewing account keeps its own progress and watched status. Profiles show viewing activity as allowed by library access rules.

## Resume an episode

Return to the episode to pick up from the previously saved position. Completed works, episodes, and films appear as different categories in viewing statistics.

## Mark something watched

Mark a whole work, an installment, or an episode as watched to record viewing from elsewhere. The manual work or installment action in Browse preserves the current playback position.

## Favorites, reviews, and comments

Favorite titles to find them again. Family-visible collections, reviews, and comments can appear on a profile. When discussing a plot detail, use spoiler formatting so others can reveal it when ready.
