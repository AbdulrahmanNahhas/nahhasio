# Start here

Nahhasio is an Arabic-first catalog, watch tracker, and media library created for one family’s collection. Start with the title you remember, then explore the recordings, people, and episodes connected to it.

## Find something to watch

Open Browse and search by Arabic title, English title, or a known alias. Switch between posters, banners, logos, and a table. Each view remembers its display preferences.

## Follow a series

Open a work to see its seasons and episodes. Viewing progress is specific to each account, so everyone can follow the same series at their own pace.

## Curate a collection

Keep metadata, artwork, and dubbing credits with the work. If you have a corresponding video, review how it matches the title or episode before importing it.
