# Save and watch offline

Saving a work keeps its viewing details and artwork on the device. Downloading a video is a separate action.

## Save a work for browsing

Use **Save work** to retain the title’s available metadata and artwork. A saved work can be browsed when the library is unavailable.

## Keep a video for playback

Use **Download to device** on the film or episode you want to take with you. Check **Downloads** for completion and play the retained file from there.

## Reconnect to sync viewing changes

Progress and watched changes can be queued while offline. Online source selection and family discussion require a connection.

## Which option do I need?

| Action               | What stays on the device                                    |
| -------------------- | ----------------------------------------------------------- |
| Save work            | Catalog details, artwork, and available viewing information |
| Download to device   | The complete video file for a film or episode               |
| Mark watched offline | A viewing change to synchronize after reconnecting          |
