# Browse the library

Search for a work the way you remember it. Browse accepts alternate titles as well as Arabic and English names.

## Choose a view

- **Posters** and **banners** emphasize artwork.
- **Logos** make familiar titles easy to spot.
- **Table** puts more titles and their details on screen.

## Narrow your results

Use filters for viewing status, release information, studios, and other catalog details. Switch layouts without losing each layout’s display preferences.

## Work or installment

Use the work view for the whole title. Use installment view when you want seasons or standalone releases as separate results. Each layout has independent presentation controls, including titles, artwork, and optional metadata.
